#  展覽雷達：雙北展覽空間與文化趨勢地圖 (Exhibition Radar)

##  專案理念 (Concept)

「展覽雷達」是一個基於 Streamlit 框架和地理空間數據 (OSMnx/Folium) 建立的互動式文化資訊平台。

專案旨在將分散在不同平台的展覽資訊與城市地理環境結合，透過可視化地圖，讓使用者能夠：
1.  **快速瀏覽** 雙北主要展館的當前展覽資訊。
2.  **查詢** 展館周邊特定半徑內的**生活便利設施** (POI, Points of Interest)，如餐廳、交通、購物等。
3.  以數據驅動的方式，重新看見雙北的文化創意和生活機能分佈。
4.  此為一個測試版本

##  主要功能 (Features)

* **模糊搜尋與定位：** 支援 `rapidfuzz` 進行展館名稱的模糊搜尋，快速定位目標場館。
* **互動式地圖探索：** 使用 Folium 繪製地圖，標示展館位置，並根據 OSMnx 數據，繪製周邊設施標記。
* **客製化周邊設施查詢：**
    * 在側邊欄自訂 POI 搜尋半徑 (500m ~ 1500m)。
    * 可選擇要查詢的設施類型，如：**餐廳、購物、住宿、交通**。
    * 利用 **MarkerCluster** 自動分組密集標記，保持地圖清晰。
* **展覽詳細資訊：** 顯示選定場館的簡介、Hashtags，並提供**展覽清單**、**數據欄位篩選**與**圖片展示**。
* **數據與環境分離：** 透過 `.env` 檔案管理敏感路徑，提高程式碼可移植性。

##  使用方式 (Tech Stack)

| 類別 | 工具/函式庫 | 用途 |
| :--- | :--- | :--- |
| **框架/介面** | Streamlit | 快速搭建互動式 Web 應用程式介面。 |
| **地理數據** | OSMnx, GeoPandas | 核心 OSM 數據查詢、處理和 GeoDataFrame 操作。 |
| **地圖繪製** | Folium, streamlit-folium | 創建和嵌入互動式的 Leaflet 地圖。 |
| **數據處理** | Pandas | 處理展覽資訊 CSV 檔案。 |
| **模糊匹配** | rapidfuzz | 高效的展館名稱模糊搜尋。 |
| **配置管理** | `python-dotenv` | 讀取環境變數。 |
